# 💅 Safiro Nails - Centro de Control del Proyecto

Bienvenido al repositorio central de **Safiro Nails**. Este proyecto se gestiona bajo la metodología **Document Driven Development (DDD)**, donde la documentación guía el desarrollo y las decisiones técnicas.
