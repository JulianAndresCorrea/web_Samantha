# 🎨 Sistema de Diseño - Safiro Nails

Este documento define las bases visuales para mantener la consistencia y la elegancia de la marca Safiro Nails.

## Paleta de Colores

| Color | Hex | Uso |
| :--- | :--- | :--- |
| **Primary** | `#8E7B6A` | Botones principales, acentos destacados, títulos. |
| **Secondary** | `#C4B5A5` | Elementos decorativos, hover en botones. |
| **Background** | `#F9F7F5` | Color de fondo principal (blanco hueso/arena). |
| **Text** | `#2D2D2D` | Texto principal para máxima legibilidad. |
| **Text Muted** | `#666666` | Descripciones y textos secundarios. |
| **Accent/Dark** | `#333333` | Footer, contrastes fuertes. |

## Tipografía
- **Fuente Principal:** `Outfit` (Google Fonts). Elegida por su apariencia moderna, limpia y geométrica.
- **Jerarquía:**
  - `h1`: 3.5rem (Hero)
  - `h2`: 2.5rem (Secciones)
  - `h3`: 1.5rem (Cards)
  - `p`: 1.1rem (Cuerpo)

## Componentes Clave

### Botones
- Bordes redondeados sutiles (0px para look editorial o muy poco radio).
- Transiciones suaves de color al pasar el cursor.

### Galería
- Grid responsivo (1 columna en móvil, 2 en tablet, 3 en desktop).
- Hover con overlay elegante para indicar interactividad.
- Lightbox con fondo desenfocado (backdrop-filter).
